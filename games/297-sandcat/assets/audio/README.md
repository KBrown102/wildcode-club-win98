# 音频替换说明 · 落沙 · 引猫夜

游戏**默认零文件**：所有背景音乐与音效都是 WebAudio 现场合成的，直接双击 `index.html` 就有声音。

如果你想换成自己的音频，把同名文件放进这个目录即可 —— 放进去就自动接管，没放的继续用合成音，**缺任何一个都不会报错**。

## 目录与文件名

```
assets/audio/
├── bgm.mp3                 ← 背景音乐（循环播放）
└── sfx/
    ├── tap.mp3             ← 轻点一下（落一格沙）
    ├── land.mp3            ← 沙粒落地
    ├── shovel.mp3          ← 铲起一铲沙
    ├── lamp.mp3            ← 猫走过，地灯点亮（会按五声音阶变调）
    ├── meow.mp3            ← 猫被卡住时叫
    ├── home.mp3            ← 一只猫到家（会按五声音阶变调）
    └── win.mp3             ← 全城通关
```

同名的 `.ogg` / `.wav` / `.m4a` 也可以，但文件名必须一致（见 `manifest.json` 里的 `files` 列表）。

## 建议

| 槽位 | 时长 | 说明 |
|------|------|------|
| `bgm.mp3` | 60s 以上无缝循环 | 放了它，合成的环境底噪会自动让位（音量归零），不会叠在一起 |
| `tap` / `land` | 40–120 ms | 这两个触发最密集，太长了会糊 |
| `lamp` / `home` | 0.3–1.0 s | 游戏会按五声音阶（宫商角徵羽）改变播放速率来变调，音高最好是 C 调单音 |
| `meow` | 0.2–0.4 s | |
| `win` | 1.0–2.0 s | |

## 怎么确认替换成功了？

浏览器控制台里执行：

```js
SANDA.externalCount()    // 返回已成功加载的外部音频数量
SANDA.hasExternal('bgm') // true 表示 bgm.mp3 已被接管
```

注意：**本地直接双击打开（file://）时，部分浏览器会拦截 Audio 解码**，此时会自动回退到合成音，属正常现象。部署到线上（http/https）后外部音频必定生效。

## 音量

合成音的总音量写死在 `js/audio.js` 顶部的 `VOL`（master 0.55 / bgm 0.40 / sfx 0.90）。外部音频文件的音量由 `playSample()` 里的系数控制，想调小直接改那几个数字。
